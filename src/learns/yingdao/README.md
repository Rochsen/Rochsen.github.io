## 第一节课考试内容

```text

【题面】登录影刀商城，在订单管理页面，对所有商品名称为帽子的订单进行批量发货。

步骤拆解：
● 打开影刀商城页面，网址 https://shop.yingdao.com/
● 输入用户名“admin”和密码“58T2$!hm”，并点击“登录”按钮
● 切换到“订单管理”页面
● 填写商品名称“帽子”，点击“查询”搜索
● 依次点击所有帽子订单的“确认发货”及“确定”


【重难点提示】
● 进入影刀商城首页，登录后没有弹出新的网页页面，所以网页对象始终是同一个，没有发生改变
● 多个确认发货按钮，可以作为一个相似元素组进行操作


【易错点提示】
● 首次使用影刀，记得安装自动化插件
● 元素后面带web，表示用于网页自动化；元素后面带win，表示用于桌面软件自动化，注意分辨~

```
