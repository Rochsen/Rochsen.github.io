硅基流动（弃用）

提示

硅基流动拥有GLM-5.2、Kimi-2.7-coder等较新模型，但是老模型较多，调用的时候会导致调用到非指定模型，体验过后就退款了

没有套餐，直接充钱使用（按调用模型的价格计费）

CC-Switch

官网：https://www.ccswitch.io/zh/

下载：https://github.com/farion1231/cc-switch/releases

用于管理 Claude、Codex、OpenClaw等agent工具模型的软件，国内用户通常接入国产大模型来跳过账号注册步骤

Agent

Claude（弃用）

这个可以看B站up主 @数字游牧人 关于 Claude 的安装和配置，因国内阿里发现该软件存在恶意检测行为，软件个人使用一段时间后就卸载了，因此找到了替代品 codex

Codex

需要科学上网，进入 openAI 官网下载 ChatGPT（codex和gpt已经合并），有桌面版本和cli版本，桌面版本可以在微软商店下载，需要保持电脑可更新的状态

Hermes

中文社区：https://hermesagent.org.cn/

支持自进化的Agent，同样拥有桌面版本和cli版本的工具，同时桌面版本可以在中文社区下载，可以像openclaw那样接入到飞书或者微信中，接入飞书可能可以创建更多的聊天框
